这是一个基于 MNIST 数据集的最小可运行 Latent Diffusion Model（LDM）实验，用于演示扩散模型在低维隐空间中学习图像生成的基本流程。项目整体思路分为三步：先用 VAE 将手写数字图像编码到低维 latent space，再在该隐空间中训练一个简单的扩散模型，最后从随机噪声开始逐步去噪，生成新的数字图像。

该实现重点在于理解 LDM 的核心思想，而不是追求最强的生成质量，因此网络结构保持简单，适合用于学习、调试和实验。它包含完整的训练过程：数据加载、VAE 训练、扩散模型训练、采样生成图像以及可视化结果。

在代码中，VAE 负责将 28×28 的灰度图像压缩到 32 维潜变量空间，并通过重构损失与 KL 散度进行训练。随后，扩散模型在 latent space 中学习如何从噪声 latent 预测添加的噪声，并使用线性 beta schedule 进行前向扩散。采样时，模型从随机高斯噪声开始，按时间步反向去噪，最终通过 VAE decoder 恢复出图像。

该项目的优点是结构清晰、依赖较少、容易修改，适合初学者理解 Latent Diffusion Model 的训练机制。它也可以作为进一步扩展的基础，例如升级为更强的 U-Net 扩散模型、加入时间步嵌入、提升采样流程或扩展到更复杂的数据集。

这个实验适合用于学习：VAE 如何压缩图像、扩散模型如何在隐空间中训练、以及采样时如何逐步恢复图像。
